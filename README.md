# BIG SOLIS — Official Website

Production source for **https://elbigsolis.com**.

## Publish with Cloudflare Pages

This is a static site. No build command is required.

- Framework preset: None
- Build command: leave blank
- Build output directory: `/` (repository root)
- Production branch: `main`
- Custom domain: `elbigsolis.com`

## Common updates

- Homepage content: `index.html`
- Images and cover art: `assets/`
- Privacy page: `privacy.html`
- Search engine files: `robots.txt` and `sitemap.xml`

## Direct music sales

The Pay What You Want UI is included, but checkout is intentionally disabled until a secure payment/download provider is connected. Do not enable the checkout button until payment links and downloadable files are configured.

Canonical site URL: `https://elbigsolis.com/`
